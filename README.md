# RS Voice — обновления по воздуху

Здесь лежит то, что машина проверяет сама: манифест `update.json` и сборка, разрезанная
на куски (GitHub не отдаёт файлы больше 100 МБ, а APK с моделями весит ~173 МБ).

Машина раз в 10 минут читает `update.json`, сравнивает `version_code` с установленным,
скачивает куски по порядку, склеивает, сверяет `sha256` целого файла и ставит **без
подтверждения** — приложение обновляет само себя и перезапускается.

## Выложить новую версию

```bash
# 1) собрать (versionCode обязательно больше предыдущего)
cd rsvoice_app && ./gradlew assembleDebug

# 2) порезать и посчитать хэш
APK=app/build/outputs/apk/debug/app-debug.apk
rm -f apk/RS_Voice.apk.a*
split -b 80m "$APK" apk/RS_Voice.apk.
shasum -a 256 "$APK"        # это значение → в update.json

# 3) поправить version_code, version_name, sha256 в update.json
#    (если кусков стало больше/меньше — поправить и список parts)

# 4) выложить
git add -A && git commit -m "RS Voice 2.6" && git push
```

Через 10 минут все машины обновятся сами. Проверить вручную:
**RS Voice → Настройки → О приложении → «Обновить»**.

## Запасной путь без интернета

Положить `RS_Voice.apk` на флешку (в корень или в папку `Download`) и вставить в машину —
агент найдёт его сам и поставит.

## Важно: куски кладутся в папку своей версии

Имена кусков раньше были одинаковыми для всех версий (`apk/RS_Voice.apk.aa`), а `update.json`
и куски кэшируются на CDN по отдельности. В момент выкладки машина могла взять новый манифест
и ещё старые куски (или наоборот) — склеенный файл не сходился по sha256, и обновление честно
отказывалось ставиться с «sha не совпал».

Поэтому теперь **каждая версия лежит в своей папке**: `apk/v32/RS_Voice.apk.aa` и так далее,
а `update.json` ссылается именно на неё. Старые папки не удаляем — по ним ещё могут прийти
машины со старым (закэшированным) манифестом.

```bash
V=33                                   # versionCode новой сборки
mkdir -p apk/v$V
split -b 80m app-debug.apk apk/v$V/RS_Voice.apk.
shasum -a 256 app-debug.apk            # это значение → sha256 в update.json
# в update.json: version_code, version_name, sha256 и parts на apk/v$V/...
git add -A && git commit -m "RS Voice X.Y" && git push
```
